# Profile Structure

This profile intentionally follows a visual information architecture rather than a CV layout:

1. **Hero** — identity and primary security focus.
2. **Security Profile** — one concise positioning statement.
3. **Security Core** — visual map of the operating model.
4. **Capability Matrix** — four high-value capability areas.
5. **Selected Work** — practical work expressed as outcomes/capabilities instead of a long tool list.
6. **Experience** — compact timeline plus concise descriptions.
7. **Security Arsenal** — tools and technologies.
8. **Credentials & Research** — certifications and research.
9. **GitHub Telemetry** — live GitHub widgets.
10. **Security Operating Model** — the offense-to-defense mindset.
11. **Contact** — simple closing panel.

The SVG animations are deliberately concentrated in the hero, core, timeline, dividers and footer. This keeps the profile visually distinctive without making every line of text move.
