## 🛡️ Security Profile

I am a **Cybersecurity Analyst focused on SOC operations, VAPT and offensive security**, with hands-on experience building and tuning security monitoring capabilities using **Wazuh SIEM/XDR**, endpoint telemetry, firewall logging, custom detection rules, dashboards and threat-focused investigations.
